S. Udhaya — Animated Portfolio

1. Extract this ZIP file.
2. Keep index.html, style.css, script.js and assets folder together.
3. Open index.html in Chrome or Edge.

Includes responsive layout, animated hero, typing role text, scroll reveal effects,
animated project illustrations, mobile navigation and downloadable resume.

The initials SU are used as the profile visual because no profile photograph was
included in the resume. GitHub and LinkedIn URLs were not supplied, so none have
been invented. Add those URLs to the contact section in index.html if available.
